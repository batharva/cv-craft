
# CV Craft — Online Resume Builder

A web-based platform created to make an existing LaTeX resume template more accessible and easier to use. This project converts a resume template originally developed by IIT Tirupati seniors into a website, allowing students to access and customize their resumes more conveniently.

## 🚀 About the Project

Creating and maintaining a professional resume using LaTeX can be challenging for students who are unfamiliar with its syntax. **CV Craft** aims to simplify this process by bringing the resume template to the web.

The original LaTeX code was developed by seniors from IIT Tirupati. I adapted their work into a website to improve accessibility and make the template easier for students to use.

### Key Objectives
- Make the existing resume template easily accessible through a website.
- Simplify the process of using and customizing the resume format.
- Help students create professional resumes without manually navigating the original LaTeX source code.
- Preserve the contributions of the original developers while improving usability.

## ✨ Features

- 🌐 Web-based access to the resume template.
- 📄 Based on the original LaTeX resume format.
- 🎓 Designed to make resume creation more accessible for students.
- 🛠️ Adapted from an existing student-developed project.
